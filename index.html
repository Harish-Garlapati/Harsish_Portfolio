Live · company loan CRM

Multi-bank Statement Analyzer

Every bank formats statements differently, and loan decisions depend on getting every transaction right. I built a Python engine with OCR that reads statements from most Indian banks and runs alongside the CRM's Node.js backend.

  • Found and fixed silent data corruption on one bank's detailed statements
  • Stopped double-counting across overlapping statement periods
  • Reconciled 7,561 transactions by hand to prove accuracy

Result: review time cut from 30+ minutes to under 2, with no numeric errors reported in production.

Python · pdfplumber · OCR · Node.js · Angular · MySQL

Live · company loan CRM

CIBIL Credit Report Analyzer

Credit reports are long PDFs that officers used to read line by line. I built a parser that turns them into a clear dashboard, structured data and Excel, then ported it from Python to Node.js and Angular so it lives inside the CRM.

  • Matched output across two PDF libraries with a documented compatibility layer
  • Proved the port with a 51-file regression suite
  • Score, loan accounts, overdue days and enquiries in one searchable view

Result: 100+ credit reports analyzed, live in the CRM with role-based access.

Python · FastAPI · Node.js · Angular 17 · pdf.js
